## Projetos em destaque

### Preventivo — aplicação web para acompanhamento de negociações

Criei o Preventivo para organizar promessas e acordos de pagamento, acompanhar vencimentos e facilitar consultas durante o atendimento. A ferramenta surgiu de uma necessidade identificada em uma **operação de cobrança de produtos financeiros de uma grande empresa brasileira do varejo de moda**.

Atualmente, cerca de **15 outros profissionais** utilizam e avaliam a solução, contribuindo com sugestões para sua evolução.

**Recursos:** busca, alertas de vencimento, indicadores operacionais, confirmação manual de pagamentos e armazenamento local criptografado.

**Tecnologias identificadas:** HTML5, CSS3, JavaScript e Web Crypto API. Desenvolvimento apoiado por GPT/Codex.

[Conhecer o Preventivo](projetos/preventivo/README.md) · [Como surgiu e onde é utilizado](projetos/preventivo/CONTEXTO-PROFISSIONAL.md)

### Eternal Ascension TD — jogo para Windows e presença web

Desenvolvo o **Eternal Ascension TD**, um jogo independente de estratégia *tower defense*, com personagens, cenários, progressão, animações e evolução de mecânicas. O projeto também possui um **site oficial**, que apresenta seu universo visual e direciona visitantes à distribuição na Microsoft Store.

**Jogo:** publicação para Windows em pacote MSIX, desenvolvimento iterativo e testes de qualidade.

**Site:** apresentação do produto, personagens, galeria de mapas e notas de versão, hospedado no Cloudflare Pages.

[Estudo de caso do jogo](projetos/eternal-ascension-td/README.md) · [Estudo de caso do site](projetos/eternal-ascension-td/site/README.md)
